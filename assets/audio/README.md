# HolyMind micro-sonic identity

Fourteen original, reproducible DSP compositions. They combine muted modal resonators, shaped seeded friction/noise, a warm impact body, deliberate irregular note timings and short early reflections. These are synthesized sound designs, not recordings of actual glass/metal/ceramic and not output from a generative audio model.

Browser synthesis and the downloadable WAVs use the same `holymind-timbres.js`. The WAV previews are dry mastered assets; live playback adds a controlled master gain, gentle compression and up to ±1.5% pitch variation. No continuous music, third-party sample or external request.

Run `npm run build:sounds` to reproduce these files. Source and generated assets are supplied with this website for its owner.
