# HolyMind Digital + Electricity — v12

Fourteen original, reproducible DSP sound designs built for HolyMind. The new sonic grammar is a short charge sweep, aperiodic arc crackle, clocked digital packets and a dry electrical latch. It replaces the prior glass/ceramic-like modal resonators: there are no bell-mode banks, sustained pads, stock samples, actual electrical recordings, or generative-audio-model output.

Each visual style retains its own sound mapping. The rare Prime and Triad styles have longer signature charge sequences. Grain windows, harmonic pulse packets, DC removal, two low-pass stages, per-preset peak/RMS control and short fades keep the design bounded; this is not a certification of perceived loudness or physical-device hearing safety.

32 kHz, mono PCM. Browser playback and these WAVs share the same `holymind-timbres.js`. Live playback retains a 0.48 default user gain, compression, three-voice limit, gesture unlock, persistent mute/volume, and no continuous background soundtrack. ±1.5% rate variation is kept subtle. Visuals and motion are independent of sound.

Rebuild with `npm run build:sounds`. The previous v11 WAV files remain in the parent audio folder for comparison. No copyrighted third-party audio is included.
