# Quiet Current — controlled listening previews

The three comparisons use the production Web Audio graph, three identical Electric v12 taps, a fixed 22-second down/pause/up gesture score, 0.48 master gain and the same compressor. They are not separately normalized. The two isolated stems use the same level. No generative model, recording, external sound pack or new runtime library is used.

These are illustrative scripted gestures, not microphone recordings from an iPhone or proof of subjective sound quality. Browser output may differ slightly across engines and devices. Run scripts/render-soundscape.cjs with the preview server running to reproduce them.
