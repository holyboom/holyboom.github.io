# HolyMind brand assets

The HolyMind brain and 34 skill marks are original HolyMind Framework artwork, used for Theerawee Rangram’s personal website at his direction.

Source artwork: HolyMind plugin asset collection, version 0.1.6. The supplied visual reference identifies the same purple pixel-art brand language.

The website derivatives retain the source artwork and transparency. Changes are limited to responsive resizing and image compression. The main brain is provided at 960 and 480 pixels; skill marks at 256 pixels; the favicon at 96 pixels.

The source package identifies its license as `Proprietary-HolyMind-Internal`. These assets are not represented as an open-source icon library. Rights remain with the original owner.

## Fonts

Sora (variable, weights 100–800) and DM Sans (variable, weights 100–1000) are self-hosted Latin WOFF2 subsets obtained from Google Fonts. The unmodified SIL Open Font License notices are retained in `fonts/Sora-OFL.txt` and `fonts/DM-Sans-OFL.txt`.

Font sources: https://fonts.google.com/specimen/Sora and https://fonts.google.com/specimen/DM+Sans.

## Interface icons

The 10 small interface icons in `ui/` are unmodified Phosphor regular SVGs obtained from the official Phosphor Icons core repository: https://github.com/phosphor-icons/core. The MIT license is retained in `ui/PHOSPHOR-LICENSE.txt`.
