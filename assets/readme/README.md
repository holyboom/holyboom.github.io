# Engineering fieldnotes plates

Original editorial compositions for this repository README: warm paper / ink, large serif typography, engineering annotations and unchanged HolyMind artwork. They are deliberately different from the violet-neon, scroll-driven website. Mobile and desktop crops have separate compositions; light/dark versions follow the reader’s GitHub theme.

The PNG plates are static and do not contain scripts, tracking or external embedded resources. Text meaning is repeated in native Markdown, and each plate has alternative text. Core navigation and contact links remain native Markdown/HTML links.

Source: `scripts/readme-plates.html` and `scripts/build-readme.cjs`. The renderer uses Instrument Serif (Google Fonts, SIL OFL) only at build time, and the repository’s existing DM Sans for labels. No new font binary is distributed with these plates or the downloadable README bundle. Original brain/skill image bytes are unmodified. Rights remain with their original owners; see `../brand-attribution.md`.
