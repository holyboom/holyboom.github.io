Theerawee Rangram

ผมเชื่อมโยงความต้องการทางธุรกิจ สถาปัตยกรรมซอฟต์แวร์ และการลงมือพัฒนาเข้าด้วยกัน ผมเริ่มพัฒนาความสามารถด้าน AI ในปี 2567 ขณะที่ยังทำงานอยู่ ttb โดยมุ่งเน้นการนำ GenAI มาประยุกต์ใช้กับงานจริง การออกแบบ Agentic Workflows และระบบอัตโนมัติที่กำหนดสิทธิ์เข้าถึงข้อมูลชัดเจน มีขั้นตอนให้คนตรวจทาน และสืบย้อนหลักฐานอ้างอิงได้
ประสบการณ์พัฒนาและส่งมอบซอฟต์แวร์กว่า 9 ปีในธุรกิจธนาคาร ประกันภัย ฟินเทค และอีคอมเมิร์ซ ผู้สร้าง HolyMind Framework

บทบาทที่เหมาะจะพูดคุย (ROLE FIT)
AI Solutions Architect: แปลงความต้องการทางธุรกิจเป็นขอบเขตระบบ การเชื่อมต่อ การควบคุมสิทธิ์ และแผนส่งมอบที่ลงมือทำได้
AI Engineer และ GenAI Engineer: พัฒนาเครื่องมือที่ให้ AI ช่วยงาน เชื่อมกับแอปพลิเคชันเดิม และวางขั้นตอนประเมินผลกับการตรวจทานโดยคน
Forward Deployed Engineer: คุยโจทย์กับลูกค้า ลงมือพัฒนา และประสานงานกับทีมต่างประเทศ ตั้งแต่ทำความเข้าใจปัญหาจนส่งมอบงาน
AI Transformation Consultant: เลือกกรณีใช้งานแรกที่มีประโยชน์ ออกแบบกระบวนการและการกำกับดูแล พร้อมตกลงว่าจะประเมินผลอย่างไร
รายการนี้เป็นบทบาทที่เหมาะนำมาพูดคุย ไม่ใช่รายชื่อตำแหน่งทั้งหมดที่เคยดำรง ขอบเขตงาน ความพร้อมเริ่มงาน และเงื่อนไขต้องตกลงกันอีกครั้ง

ความเชี่ยวชาญหลัก (CORE CAPABILITIES)
พื้นฐานการพัฒนาซอฟต์แวร์องค์กรควบคู่กับการออกแบบสถาปัตยกรรม AI เชิงประยุกต์ ได้แก่ การเชื่อมต่อ GenAI, Agent Orchestration, การประเมินผล LLM (LLM Evaluation), Guardrails, การเชื่อมต่อ API และการออกแบบจุดตัดสินใจที่มีคนร่วมตรวจทาน (Human-in-the-loop) ส่วนงานพัฒนาแอปพลิเคชันครอบคลุม TypeScript, React, Angular, FastAPI และ PostgreSQL Row-Level Security

ประสบการณ์ที่คัดสรร (SELECTED EXPERIENCE)
Independent AI Solutions Architect
ออกแบบและพัฒนาเครื่องมือที่ใช้ AI ช่วยงาน ด้วย React, FastAPI และ PostgreSQL ตั้งแต่ทำความเข้าใจโจทย์ วางสิทธิ์เข้าถึงข้อมูล ไปจนถึงการแสดงที่มาของคำตอบและจุดที่ต้องให้คนตรวจทาน

ผลงานที่เปิดเผยแพร่ (PUBLIC WORK)
เว็บไซต์ตัวอย่างที่ทำงานบนเบราว์เซอร์ แสดงแนวคิดการออกแบบการโต้ตอบ ขอบเขตขั้นตอนการทำงาน และวิศวกรรมซอฟต์แวร์ ผู้เข้าชมสามารถสำรวจโจทย์ตัวอย่าง 3 สถานการณ์ ตรวจสอบตัวอย่างการเชื่อมโยงข้อมูลอ้างอิงสมมติสู่ผลลัพธ์ และนำสิ่งที่เลือกไปต่อยอดเป็นข้อมูลตั้งต้นสำหรับคุยงานต่อ
ผลงานที่เผยแพร่นี้เป็นตัวอย่างสาธิตในพอร์ตโฟลิโอ ไม่ใช่บริการ Agent ที่กำลังทำงานให้ลูกค้าจริง หรือผลลัพธ์ทางธุรกิจที่นำมาอ้าง ส่วนโค้ด ข้อมูลส่วนตัว และเอกสารลับของลูกค้าไม่ได้เผยแพร่บนเว็บไซต์นี้
