ภาพเดิมมาจากเว็บจริง `living-new-era-v30` ภาพใหม่มาจากรุ่น `living-paper-flight-v31` ก่อนเผยแพร่ คลิปใช้ Chromium ขนาด 393 × 800 จับภาพ 103 ตำแหน่งเลื่อนเดียวกัน โดยตัดจากฉากเฟืองไปยังคำเชิญท้ายบท แล้วเลื่อนต่อถึงช่วงกระจายสกิล เล่นเทียบกันที่ 12 ภาพต่อวินาที ภาพนิ่งภาษาไทยใช้ WebKit ส่วนจอใหญ่ภาษาอังกฤษใช้ Chromium

| คำอ่านในภาพตัวอย่าง | scrollY บน WebKit 393 × 800 | สิ่งที่เห็น |
| --- | ---: | --- |
| “ผมคัด ทดลอง และปรับแก้…” | 8791 | เฟืองทองเหลืองกับเฟืองสีน้ำเงินขบกันบนแท่น ตัวชิ้นงานรวมฐานกว้างประมาณ 151 CSS px จากเดิม 23 px |
| “อ่านเรื่องภาพเคลื่อนไหวและเสียงที่เชื่อมกัน” | 12413 | เครื่องบินกระดาษมีปลายแหลม ปีก และแนวพับที่ถุงมือจับ ชิ้นงานกว้างประมาณ 126 CSS px จากเดิม 44 px |

ในฉากท้าย ภาพลำดับแสดงแบบร่าง สมุด คู่เฟือง เส้นที่เดินทางถึงศีรษะ และแสงที่กระจายออกตามลำดับ ตรวจการเลื่อนไปข้างหน้า ย้อนกลับ หยุดกลางช่วงแสง และสลับแท็บจริงบน Linux ระหว่างหยุด ตำแหน่งของเรื่องคงที่และแสงที่ศีรษะยังเดินต่อ เมื่อซ่อนแท็บ ทั้งจำนวนเฟรมที่วาดและเวลาของแสงหยุดนิ่ง ตรวจจอภาษาไทย 393 × 654 และ 393 × 800 เพิ่มเติมตลอดช่วงแสงกระจาย เพื่อยืนยันว่าหัวข้อ “งานที่ผ่านมาโดยสรุป” อยู่ถัดจากพื้นที่วาด ขนาดจอมือถือและการสัมผัสเป็นการจำลองในเบราว์เซอร์
