# เส้นใยส่งจรวดกระดาษออกจากมือ

ภาพคู่นี้จับที่ตำแหน่งเลื่อนเดียวกันบนหน้าอังกฤษ ก่อนปรับ เส้นทั้งสองข้างหายทันทีที่คำบรรยายเปลี่ยนเป็น “What the work leaves with me.” หลังปรับ เส้นจากบรรทัดที่กำลังอ่านและเส้นริมจออยู่ต่อ ปลายเส้นย้อนขึ้นมารวมที่รอยพับขณะที่มือยังประคองกระดาษ เมื่อมือปล่อย เส้นเหยียดตามแนวบินแล้วจางไปพร้อมจรวด

[คลิปเลื่อนเทียบก่อนและหลัง](plane-return.mp4) · [ภาพนิ่งสี่จังหวะพร้อมภาพขยายรอยพับ](plane-return.webp)

คลิปมาจาก Chromium ภาพนิ่งมาจาก WebKit ทั้งสองจำลองพื้นที่หน้าเว็บขนาด 393 × 654 พิกเซล CSS

[ตำแหน่งเลื่อนที่ใช้เปรียบเทียบและผลวัดจากเบราว์เซอร์](browser-review.json)

ในหน้าไทยทดลองเพิ่มความยาวของข้อความท้ายบทเฉพาะในเบราว์เซอร์ เมื่อข้อความขึ้นบรรทัดใหม่ จุดเริ่มดึงเส้นเลื่อนตามความสูงของบท เส้นยังเริ่มจากข้อความที่เห็นและย้อนกลับมาหาบรรทัดเดิมได้
