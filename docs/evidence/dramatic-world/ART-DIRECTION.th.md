# ฉากแวดล้อมเพื่อขับอารมณ์ของเรื่อง

| Section | องค์ประกอบและอารมณ์ |
| --- | --- |
| เปิดเรื่อง | ผิวใย A อยู่ท่ามกลางเส้นร่างของพื้นที่ที่ยังเป็นความเป็นไปได้ |
| ความฝันเรื่องสถาปัตยกรรม | แบบร่าง ม้วนเอกสาร โครงอาคาร ซุ้มทางเข้า และเส้นฐานของสถานที่ที่ยังไม่เสร็จ |
| สร้างระบบองค์กร | เสาชิ้นส่วน ชั้นระบบ และสะพานที่เชื่อมหน่วยงานเข้าด้วยกัน |
| ทำงานร่วมกัน | กลุ่มจุดเชื่อมต่อ พื้นที่ทำงานหลายตำแหน่ง และเส้นที่ทอดข้ามระยะห่าง |
| คนตรวจทาน AI | ประตู ขอบเขต และแผงหลายชั้น สื่อถึงการหยุดตรวจและการตัดสินใจ |
| ยืนหยัดคนเดียว | เก้าอี้ว่าง พื้นที่งานที่หลงเหลือ ซุ้มกั้น และทางเชื่อมขาด; เปลี่ยนเป็นเศษบทเรียน แล้วกลับมาต่อกันเมื่อเริ่มซ่อมและลุกขึ้น |
| ประสบการณ์ตกผลึก | เอกสารลอย ตัวแทนคลังความรู้ ใยเชื่อม และกลีบของสกิลที่เริ่มมีตัวตน |
| AI experiences | ความซับซ้อนหลายชั้น โครงทางเข้า และสะพานที่ทำให้มีทางเดินเข้าไปใช้งาน |
| ผลงานที่สำรวจได้ | แผงงานและฐานจัดแสดง ต่อกันเป็นพื้นที่ให้เข้าไปตรวจและทดลอง |
| ย้อนมองประสบการณ์ | เสาหลักและเศษรูปทรงจากบทที่ผ่านมา วางห่างกันเพื่อให้เห็นระยะทาง |
| บทใหม่ร่วมกัน | ซุ้มพื้นที่เปิด กลีบเครือข่าย และทางเชื่อมที่ชวนให้ใครอีกคนเข้ามา |

ทั้ง 11 ฉากใช้รูปทรงเส้นโค้ง ไม่มีภาพอ้างว่าเป็นสถานที่ทำงานจริง องค์ประกอบถูกวางหลายระยะในพิกัดสามมิติ จึงเปลี่ยนมุมและการซ้อนทับไปกับกล้อง การสลายเป็นฝุ่น เส้นแสงที่จำเรื่องราวไว้ และชั้นระบบเดิมยังใช้ร่วมกันได้

ตัวละครและงานในมือเป็นจุดอ่านหลัก ฉากใหม่มีการเว้นพื้นที่รอบศีรษะ มือ และชิ้นงานด้วยการจางเส้นที่เข้าใกล้ แทนการย้ายวัตถุตามกล้อง มือถือคงองค์ประกอบหลักหกกลุ่มและลดเส้นรอง โดยไม่เปลี่ยนเหตุการณ์ของเรื่อง
