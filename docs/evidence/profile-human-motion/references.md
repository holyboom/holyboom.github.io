## การกำกับที่ได้จากการเปรียบเทียบ

- **วาด → ตรวจงาน (A, K, M, P)** จัดฐานให้มือรองนิ่ง เอียงอกเหนือโต๊ะ วางปลายดินสอก่อนสร้างเส้น ให้น้ำหนักข้อมือพาเส้นช่วงสั้น ลดความเร็วก่อนเปลี่ยนมุม ยกปลายมือ แยกศีรษะกับแผ่นงานด้วยการถ่ายน้ำหนักคืนเหนือที่นั่ง แล้วค้างสายตาบนจุดที่เพิ่งวาด กรณีนั่งใช้เอนถอยภายในฐานรองรับ กรณียืนใช้สะโพกเปลี่ยนข้าง
- **ก้มตรวจ → ยก → วาง (E, G, N, L)** หันศีรษะไปหาขอบเป้าก่อน ให้ไหล่ตาม โน้มอกและงอเข่าเข้าถึงขอบ มือประคองและมือออกแรงเข้าคนละเวลา เมื่อจับแล้วให้ขอบสัมผัสเดินทางพร้อมฝ่ามือ ดึงเข้าหาแกนตัว พอวางให้ฐานวัตถุแตะก่อนคลายมือ ใส่จังหวะนิ่งให้ผู้ชมเห็นว่าวัตถุรองรับตัวเองได้
- **ต้าน → ลังเล → กลับมาลอง (C, D, H, P)** ให้มือข้างหนึ่งเกาะเพื่อรับแรง อีกข้างยืดหรือถอนออก สะโพกอยู่ฝั่งตรงข้ามแรงดึง เปิดช่องว่างหลังปล่อยน้ำหนัก ค้างมือข้างหนึ่งใกล้ตัว หายใจเล็กน้อย กลับมองชิ้นเดิมก่อนเปิดนิ้วเพื่อจับใหม่ เปลี่ยนแนวเข้าหาชิ้นงานในครั้งที่สอง
- **สังเกต → ชี้ → เชิญ (Q, O, J)** ให้ศีรษะนำการหมุนไหล่ ใช้วงศอกยกข้อมือเข้าหาเป้าจากด้านข้าง เมื่อต้องการให้ผู้ชมสำรวจจึงหมุนฝ่ามือหงาย ลดระดับแขนและย้ายมวลตัวออกจากช่องที่แนะนำ ค้างช่องว่างนั้นไว้
- **เลือกสองชิ้น → ประกอบ (E, F, L)** จับฐานชิ้นแรกก่อน หันศีรษะมาหาชิ้นที่สอง ยกชิ้นที่สองเป็นส่วนโค้ง ใช้มือแรกชะลอและยึดฐาน มือที่สองหมุนเข้ารอยต่อจนเกือบหยุด กดสั้น ๆ ค้างผลที่สำเร็จ ปล่อยชิ้นที่ล็อกแล้วตามลำดับ ปริมาณแสงและการยืดหรือคืนตัวของเส้นใยเป็นการออกแบบเชิงสัญลักษณ์ของเว็บไซต์
