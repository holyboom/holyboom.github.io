# วัตถุในมือของคนทำงาน

[ดูคลิปสมุดก่อน–หลัง (9.8 วินาที)](book-pages.mp4) · [ดูการพลิกและหลุดจากสันทีละใบใน 12 ภาพ](book-pages.webp)

คลิปซ้ายเป็นรุ่น v28 จากเว็บที่เผยแพร่ ขวาเป็นรุ่น v29 จากหน้าโปรไฟล์ในเครื่อง ช่วงแรกเปรียบเทียบภาพ Canvas จาก Chromium ที่ตำแหน่งเลื่อน 132 จุดเดียวกัน เริ่มตรงที่สมุดเข้ามาอยู่ในมือ ไล่ไปจนแผ่นสุดท้ายแยกออกจากเล่ม ช่วงท้ายหยุดที่ต้นบท `#craft` เพื่อดูการพลิกอีกหนึ่งใบโดยไม่มีการเลื่อน

| ภาพที่ตรวจ | จอใหญ่ ภาษาอังกฤษ | จอเล็ก ภาษาไทย |
|---|---|---|
| ทั้ง 31 ฉากในรุ่น v29 | [1440 × 900](story-desktop.webp) | [390 × 844](story-mobile.webp) |
| วัตถุ 6 ชิ้นก่อนและหลังที่ตำแหน่งเดียวกัน | [แบบบ้าน ข้อต่อ เครื่องมือ ซ่อมใย โล่ และประตู](compare-desktop.webp) | [ชิ้นส่วน แผ่นตรวจ แรงต้าน ผลึก ทางเข้าระบบ และแฟ้ม](compare-mobile.webp) |

**การเทียบภาพ** ภาพทั้ง 31 ฉากใช้ตำแหน่งเลื่อนจริงตรงกันทั้งสองรุ่นทุกฉากในแต่ละขนาดจอ สองภาษาใช้ตำแหน่งตามฉากของภาษานั้น คลิปใช้เฉพาะภาพวัตถุและตัวละครที่ Canvas วาด ส่วนภาพรวมฉากเก็บข้อความและเส้นเชื่อมที่ปรากฏทับเวทีด้วย

**การตรวจเมื่อหยุดและย้อนเลื่อน** ทดสอบ 33 ตำแหน่งใน Chromium ภาษาไทยที่ 390 × 640 และ WebKit ภาษาอังกฤษที่ 393 × 654 จุดเดิมที่กลับมาตรวจ 16 คู่ต่อเบราว์เซอร์มีตำแหน่ง วัตถุ และจำนวนแผ่นอิสระตรงกัน เมื่อหยุดที่สมุด พบแผ่นที่กำลังพลิกทั้งสองเบราว์เซอร์ เมื่อการแสดงย่อยครบ 2.4 วินาที จำนวนครั้งที่วาดคงที่ ตรวจการปัดด้วยเหตุการณ์สัมผัสจำลองแยกอีกครั้ง [ผลการตรวจพร้อมตำแหน่งเลื่อน](browser-review.json)

ขนาดจอเล็กเป็น viewport จำลองบน Linux ภาพช่วงเลื่อนในคลิปเรียงตามตำแหน่งที่บันทึกและเล่นกลับที่ 18 เฟรมต่อวินาที ส่วนช่วงหยุดใช้เวลาฉาก 2.4 วินาทีที่สุ่มเฟรมจากนาฬิกาการวาดแบบคงที่ การตรวจการหยุดจริงใช้เวลาปกติของเบราว์เซอร์

## วัสดุและการกระทำตามลำดับฉาก

ตัวเลขในตารางนับจากฉากเปิดเป็นฉากที่ 1 ภาพรวมจึงอ่านตามลำดับเดียวกับหน้าโปรไฟล์ทั้งสองภาษา

| ฉาก | สิ่งที่เห็นและจังหวะที่ใช้เล่าเรื่อง |
|---|---|
| 1–3 | เส้นใยรวมเป็นคน มือวาดบนพิมพ์เขียว เมื่อลากเส้นสุดท้ายเสร็จและปลายปากกายกขึ้น หลังคาสีดินเผาจึงพับขึ้นเป็นบ้านจำลอง |
| 4–7 | กระดาษพิมพ์เลื่อนออกตามจังหวะกดแป้น ชิปเผยขาทองแดง จากนั้นตัวละครกดชิ้นส่วนเข้าฐานและอ่านผลจากเข็มบนมาตรวัด |
| 8–13 | คลิปจับแผ่นโจทย์ไว้ สายคู่เข้าขั้วคนละครั้ง สะพานโครงถักกางจากมือหนึ่งไปอีกมือหนึ่ง ปริซึมแยกสัญญาณ ตามด้วยการส่องแว่นขยายตรวจรอยและกดคันโยกบนต้นแบบ |
| 14–18 | มือประคองไฟในเปลือกที่แยกออก สายทอรับแรงจนขาด เศษในมือมีรอยรุ่ยตรงกับสายเดิม กระสวยค่อย ๆ เย็บรอยนั้น ก่อนตัวละครยืนประคองแสง |
| 19–20 | มือซ้ายรองสมุด มือขวาแตะขอบนอก กระดาษแต่ละหน้าโก่งจากสัน เมื่อหลุดมือแผ่นแรกยกสูง แผ่นถัดมาม้วนออกด้านข้าง และแผ่นสุดท้ายลอยต่ำ ชุดแผ่นตัวอย่างมีแถบสีและกางจากหมุดเดียวกัน |
| 21–25 | เส้นใยรวมเป็นผลึกมีเหลี่ยม ผลึกชิ้นเดิมฝังในโล่ สายสีหลายเส้นมารวมที่ขั้ว ตัวละครดึงทางเดินพับให้คลี่ แล้วเลื่อนตัวบอกตำแหน่งผ่านทางแยก |
| 26–29 | บัตรเชิญเลื่อนพ้นปากซอง มือจับคันเปิดประตูจนเห็นขั้นด้านใน ฝาที่เปิดถัดมาเผยลายวงจร ก่อนยื่นชิ้นงานใยสามกลีบออกจากฝ่ามือ |
| 30–31 | ประสบการณ์ไหลกลับเข้าศีรษะและกระจายเป็นสกิล เมื่อเลือกสองชิ้น เดือยทองเหลืองเข้ากับเบ้า ทั้งสองสัญลักษณ์ยังอยู่ให้เห็นตอนแสงจาง แล้วตัวละครเปิดพื้นที่สู่บทถัดไป |

ภาพขยายจับจังหวะประกบของสกิลคู่เดียวกันจากสองรุ่น ห่างกันประมาณ 0.005 วินาที [ซองเชิญ ประตู วงจร และสกิลคู่](invitation-and-skills.jpg)

บันทึกงานอ้างอิงระบุช่วงเฟรมของการพลิกหน้า การปล่อยแผ่นกระดาษ การลงรอยพับ และการวางชิ้นงานแข็งที่ใช้กำกับจังหวะในรุ่นนี้ [วิดีโออ้างอิงและเวลาที่ตรวจ](materials.md)
