# Gravity Weave — historical v3 evidence

Superseded by [Human Drama](../human-drama/REPORT.md). These captures and results describe the prior revision.

This revision returns the English profile to the owner's approved A material: a glowing purple, rounded woven membrane. It unfolds into the symbolic maker, with continuous woven terrain through the story. The narrative hooks and AI experiences emphasis remain. This is the local production artifact; no push or deployment has been made.

## Implementation

- An organic folded surface opens the page. Smooth curves replace straight polygon paths; violet fibers, softened highlights and crossing strands give the surfaces depth.
- Dense anatomical fibers form the symbolic person. Rounded membranes replace rectangular panels; soft field nodes replace boxes; undulating woven terrain replaces the rigid floor. Binary glyphs have been removed.
- Environment strands contract around the hand light and swirl before expanding into the next scene. This is deterministic gravity-inspired deformation, not a physics solver. Scrolling to the same position restores the same geometry in either direction.
- A tapered light trail follows the actual hand trajectory. Direction reversals restart the trail; stopping fades it within 750ms. Reduced motion, resize, background tabs and offscreen art clear it.
- All eleven scenes retain matching topology: 807 strands, 48 samples per strand. Adaptive detail preserves both directions of the weave. Static SVG fallbacks share the same geometry and rounded paths.
