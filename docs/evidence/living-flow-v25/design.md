# HolyMind Living Workflow v25

## Scope
Finish the approved v24 experience without another theme, song, character or section. Existing controls select the same three challenges and four stages. A finite transfer sequence makes the source-to-gate-to-output relationship visible. The excluded source has no segment into the output. The final operations state is owner review, never an automatic approval. No backend/model/analytics/submission is added.

## Inspectable illustration
Each scenario contains three deliberately fictional snippets and two possible output statements with explicit references to the first two sources. Native buttons select a source or a claim; the diagram highlights the corresponding document and accepted route. Selecting the excluded source dims output links and emphasizes the held boundary. The inspector states that these are fictional teaching examples, not retrieved facts or client documents. Sample contents do not leak into the actual planning brief.

An event-driven GSAP tween drives three tiny packets for a finite 950 ms transfer. The held packet never reaches the output. Latest visible step wins during rapid changes, no animation/sound event queue accumulates. One pending visual state can play when the illustration first becomes visible; hidden pages discard it. New transfers use the existing runtime, not a library or perpetual JS loop.

## Choice ownership
Source inspection is ephemeral and does not mutate the saved journey. Portal return focuses the selected question without changing its step/skill. Remove this skill clears only that ID. Existing v24 whitelisted session storage remains compatible. Selected-step text says explored, not completed or executed. All three illustrative scenarios and all 34 skills remain available.

## Performance and light
The prior implementation refreshed global scroll geometry twenty times in a controlled four-repeat same-step test, despite no changed choice. Current same-step rendering is idempotent; current-tab journey updates are also no-ops for unchanged values. Actual layout changes are batched and measured by geometry before requesting a refresh. This is a reduction in repeated work, not a physical-device FPS guarantee.

Gold/cyan/violet reflection retains existing intensity caps and deterministic particle input. Each color now uses its own horizontal source centroid, rather than fixed cyan/violet positions. All source artwork, recorded audio, Mozart data/order and afterglow particle geometry are preserved. New optional proof reading uses the existing audio focus behavior, not a new sound.

## Limits
Browser automation and native touch emulation are not physical iPhone audio/performance testing. No full accessibility or flashing-threshold certification is claimed. The design is illustrative and never asserts that an agent executed a request, validated client evidence or granted approval.
