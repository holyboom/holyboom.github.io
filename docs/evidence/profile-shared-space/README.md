# พื้นที่ร่วมระหว่างภาพกับข้อความบนมือถือ

เส้นใยออกจากผิวของภาพเปิดเรื่องและทอดลงมาตามช่องว่างข้างหัวเรื่อง ในบทถัดมาเส้นที่ต่อจากพื้นฉากจะบางลง ความกว้างของเส้นใยแต่ละช่วงอิงขอบตัวอักษรที่เบราว์เซอร์จัดบรรทัดจริง เมื่อข้อความกินพื้นที่มากขึ้น ภาพจะถอยไปทางขวาและค่อย ๆ จางลง

## เมื่อเกลาภาษาไทย

หัวเรื่องแรกอยู่ที่รายการ `P0340` ช่อง `thai` ใน [ต้นฉบับสองภาษา](../../../scripts/data/profile-gemini-copy.json) เขียนตามจังหวะที่ต้องการได้เลย ระบบจะให้เบราว์เซอร์ตัดบรรทัดให้พอดีจอ หากตั้งใจเว้นจังหวะที่ตำแหน่งใดเป็นพิเศษ ให้ใส่ `\n` ในค่า JSON

ภาพทดลองเปลี่ยนข้อความเฉพาะในเบราว์เซอร์ ภาพชุดนี้เทียบทั้งหัวเรื่องที่กว้างขึ้นแต่ยังสูงเท่าเดิมและข้อความที่ขึ้นบรรทัดใหม่ การทดสอบใช้ Chromium และ WebKit บน Linux โดยจำลองขนาดจอโทรศัพท์
