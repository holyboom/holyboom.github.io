# พื้นที่ของตัวละครบนจอคอม

บนโน้ตบุ๊ก 1366 × 768 ชื่อฉาก “Connect across boundaries” เคยพาดผ่านศีรษะ และคำบรรยายในฉากตรวจชิ้นงานเคยทับมือที่ชี้อยู่ ตอนนี้ชื่อฉากกับคำบรรยายมีแถวของตัวเอง ภาพระหว่างสองแถวขยายตามพื้นที่จริง กล้องตามท่าทางและชิ้นงาน ส่วนแสงที่เชื่อมข้อความเข้ากับมือจะผ่านหลังศีรษะและลำตัว

[เทียบภาพบนโน้ตบุ๊ก](desktop-story.webp) · [เทียบจังหวะจบเรื่องบนจอกว้าง](desktop-finale.webp) · [ดูคลิปก่อนและหลัง](desktop-scroll.mp4)

บนจอ 1920 × 1080 พื้นที่ภาพหลักกว้างขึ้นจาก 696 เป็น 1,049 พิกเซล ตัวละครยืนส่งจรวดกระดาษอยู่ในเฟรมจนกระดาษพ้นมือ จากนั้นภาพเคลื่อนสู่ช่วงที่ประสบการณ์รวมเข้าศีรษะและเผยสกิล 34 รายการ

ภาพคู่นี้เทียบที่จังหวะเดียวกันในเรื่อง ระยะเลื่อนของแต่ละรุ่นต่างกันได้เมื่อหน้ากระดาษตัดบรรทัดใหม่ การทดสอบใช้ Chromium และ WebKit บน Linux
