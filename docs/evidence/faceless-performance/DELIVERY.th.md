# AI experiences — งานส่งมอบ

หน้า `/profile/` เล่าเส้นทางจากความฝันเรื่องสถาปัตยกรรม ผ่านงาน frontend และการสร้างระบบ ไปสู่ AI experiences โดยใช้ตัวละครเส้นใยเชิงสัญลักษณ์31ฉาก พร้อม hooks เชื่อมแต่ละบทและประวัติย่อเรียงจากงานล่าสุด

- ท่าทางมีจังหวะเตรียม ลงมือ ตอบสนอง และหยุดให้เรื่องราวอ่านออก มือและเท้ามีจุดสัมผัสจริง สัดส่วนแขนขาคงที่
- ช่วงเผชิญอุปสรรค ทบทวน ลองใหม่ และลุกขึ้นเดินหน้าต่อ ใช้ท่าทาง ระยะภาพ และสีช่วยสื่อโดยไม่พึ่งใบหน้า
- นิ้วพิมพ์แยกจากข้อมือ ปากกาถูกวางและปล่อยก่อนพิมพ์ แผงงานไม่บังมือ ท่าเชิญเปิดพื้นที่ให้ผู้ชม
- ใยสภาพแวดล้อมยุบและก่อตัวตามการเลื่อน กล้องเคลื่อนเข้าหาและถอยออกอย่างต่อเนื่อง แสงตามมือหายเมื่อหยุด
- เปิดดูชั้นระบบด้านหลังได้โดยตัวละครไม่กระโดด รองรับการเลื่อนย้อนกลับ คีย์บอร์ด Reduced motion และจอสั้นแนวนอน
- ตัดแคชร่างกายที่ไม่ถูกใช้ ลด retained heap ในชุดวัดเดียวกันประมาณ56.6% โดยพิสูจน์ภาพก่อน–หลังการเปลี่ยนแคชตรงกัน380กรณี
