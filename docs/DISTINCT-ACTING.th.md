# ภาษาท่าทางที่แยกกันในแต่ละฉาก

ฉากเปิดเป็นผิวใย A แล้วเข้าสู่ตัวละคร 30 ท่า แต่ละท่ากำหนดแนวอก ระดับลำตัว ศีรษะ แขน ฐานเท้า และการกระทำหลักแยกกัน เป้าหมายคือให้ดูออกจากร่างกายโดยไม่อาศัยใบหน้า สี หรือเปลี่ยนเฉพาะวัตถุในมือ

| ฉาก | ภาษาร่างกายหลัก |
| --- | --- |
| Imagine a place | เอนกลับเล็กน้อย เปิดมือซ้าย มือขวาถือเส้นร่างสูงเหนือแบบ |
| Draw the first lines | ก้มลึกและบิดเข้าหาหน้ากระดาษ มือซ้ายตรึงขอบ มือขวาลงเส้น |
| Turn the drawing into an interface | โน้มเข้าหาแป้นพิมพ์ วางมือคู่ต่ำลง |
| Build one component | บิดไปอีกด้าน หลังตรงขึ้น มือหนึ่งอยู่ที่แป้น อีกมือชี้แผงงาน |
| Fit it into a larger system | เปิดมือรองรับชิ้นส่วนด้านบน มือขวาประกอบชิ้นงาน |
| Make it dependable | ใช้มือใกล้คางหยุดประเมิน โดยมืออีกข้างมีจุดรองรับ |
| Listen to the requirement | ยืนรับฟัง มือยกข้างแนวศีรษะ อีกมือถือโจทย์ |
| Connect across boundaries | ถ่ายน้ำหนักข้างหนึ่ง แขนต่างระดับ เชื่อมจุดไกลกัน |
| Bring the pieces together | เปิดแขนออกทั้งสองด้านแล้วปล่อยชิ้นส่วนให้เป็นระบบ |
| Invite intelligence into the workflow | โน้มเข้าหางาน มือหนึ่งที่แป้น อีกมือยกไปยังชั้น AI |
| Pause at the review boundary | ย่อระดับ ก้มและเอียงเข้าไปตรวจผลอย่างใกล้ชิด |
| Keep the person in control | ยืดอกถอยจากงาน เปิดฝ่ามือเป็นขอบเขตการตัดสินใจ |
| Hold on to the possibility | ห่อลำตัวและก้มศีรษะ มือสองข้างประคองแสงใกล้กัน |
| Meet the resistance | เกร็งตั้งรับและเอนกลับ มือหนึ่งค้ำ อีกมือเผชิญแนวแตก |
| Stay with the problem | ลดชิ้นงานลงใกล้ตัก ก้มและบิดมองเศษบทเรียน |
| Return to the work | โน้มเข้าไปอีกครั้ง มือรองเตรียมก่อนมือที่ซ่อม |
| Keep the light alive | ลุกหลังถ่ายน้ำหนัก เปิดอก มือถือแสงอยู่ใกล้ตัว |
| Keep the lesson | ถือบทเรียนมือเดียว อีกมือกลับมาแตะใกล้หัวใจ |
| Look beyond my own methods | แยกเท้าเยื้อง เปิดแขนเลือกจากหลายแหล่ง |
| Distil a capability | ย่อลงอย่างชัดเจน ลดระดับงาน และประคองแกนด้วยมือคู่ |
| Build a distinctive advantage | ยืดตัว มือหนึ่งรองขอบ อีกมือเปิดป้องกันด้านบน |
| Face the hidden complexity | ฐานกว้าง บิดอกอีกด้าน แขนเชื่อมโครงข่ายต่างระดับ |
| Shape a clear way in | ย่อเข่าและโน้ม ทำทางเข้าเป็นแนวนอนด้วยมือข้างเดียว |
| Give the person agency | เอนออกจากพื้นที่ตัดสินใจ ฝ่ามือเสนอทางเลือกต่ำลง |
| Make the experience inviting | เปิดแขนสองข้างกว้างขึ้น ให้พื้นที่กับผู้ชม |
| Open the door | แขนหนึ่งชี้เชิญออกด้านข้าง อีกแขนเปิดต่ำกว่า |
| Make the work inspectable | ย่อและเอียงใกล้เอกสาร ดึงมือกลับให้เห็นสิ่งที่ตรวจ |
| Offer the next possibility | มือหนึ่งเสนอข้างหน้า อีกมือประคองใกล้ลำตัว |
| Reflect | มือกลับมารวมใกล้เอว ไหล่และศีรษะสงบ |
| Begin | เปิดแขนเป็นแนวทแยงขึ้น พร้อมมืออีกข้างยื่นรับ |

การเปลี่ยนฐานเท้าของท่ายืนใช้ก้าวทีละข้าง เท้าที่ยังลงน้ำหนักไม่เลื่อน ช่วงนั่ง–ลุกยังมีลำดับจุดรองรับก่อนถ่ายน้ำหนัก แขนขาคงความยาวเดิม และพื้นผิวงานกับจุดสัมผัสของมือใช้พิกัดร่วมกัน

การตรวจเชิงตัวเลขป้องกันท่าที่เกือบซ้ำกัน แต่ไม่ได้พิสูจน์ว่าผู้ชมทุกคนอ่านอารมณ์ตรงกัน จึงมีทั้งภาพโครงร่างสีเดียวจากกล้องเดียว ภาพ Canvas จริงครบทุกฉาก และวิดีโอการเลื่อนให้ตรวจด้วยสายตา
